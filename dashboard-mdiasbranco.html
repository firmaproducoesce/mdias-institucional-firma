Configurar JSONBin.io
Como configurar (uma única vez):
1. Acesse jsonbin.io → crie conta gratuita
2. Vá em API Keys e copie sua Master Key
3. Cole abaixo e clique em "Conectar e criar bin"
4. Copie o snippet gerado → cole no index.html → git push
✓ Após o push, o dashboard sincroniza automaticamente em qualquer navegador — o cliente não precisa configurar nada.
ⓘ O bin é público para leitura — qualquer pessoa com o link do dashboard vê os dados atualizados. Só quem tem a API Key consegue modificar. A chave fica salva apenas neste navegador (admin).
